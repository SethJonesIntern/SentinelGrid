# Sentinel Grid Machine Learning
This folder contains the machine learning portion of Sentinel Grid. 

In the notebooks folder, are all the Jupyter Notebook files that were used to perform data preprocessing, feature extractions, anomaly clustering, and behavior analysis on both test sample data and the data that our Sentinel Grid honeypots have collected. 

There is also a `requirements.txt` file that contains all the dependencies and packages needed to run the `.ipynb` files. 
It can be downloaded by navigating to the notebooks folder, creating an env if preferred, and running `pip install -r requirements.txt`

In the data folder, it contains all the test data used, the cowrie logs, and any outputs generated by using that data. More information can be found in the `README.md` in the data folder itself.
